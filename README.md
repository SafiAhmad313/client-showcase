# Nexus Craft Studio — Client Showcase Website

An ultra-modern, high-performance scrollytelling web application designed and built for client demonstration in `c:\xampp\htdocs\CIT331\client-showcase\`.

---

## 🚀 How to View the Website

### Method 1: Via Apache XAMPP (Localhost)
If Apache is running in XAMPP:
Open your browser and navigate to:
**`http://localhost/CIT331/client-showcase/`**

### Method 2: Direct File Open
Double-click `index.html` or open:
`c:\xampp\htdocs\CIT331\client-showcase\index.html` in Chrome, Edge, Safari, or Firefox.

### Method 3: Built-in Node.js Server
```powershell
cd "c:\xampp\htdocs\CIT331\client-showcase"
npm start
```
Then visit `http://localhost:3000`.

## ✨ Features & Polish Updates

1. **Razor-Sharp Modern Typography (No Pixelation or Blur)**:
   - Uses High-DPI Canvas (`mockup-generator.js`) with native Google Web Fonts (`Plus Jakarta Sans`, `Space Grotesk`, `JetBrains Mono`).
   - Clean, professional SaaS platform layout ("Aether Cloud OS"): real headlines, navigation links (`Platform`, `Solutions`, `Infrastructure`, `Developers`, `Pricing`), real metrics (`99.999% SLA`, `8.4ms Latency`, `4.8M / s Workloads`), smooth bezier curve telemetry charts, and regional status indicators.
   - Removed duplicate browser address bars.

2. **Clean Mobile Viewport (No Bulky Physical Phone Hardware)**:
   - Replaced the clunky phone case with a sleek, modern **Responsive Mobile Viewport Card**.
   - In **Vertical Mode (↑)**: Displays portrait mobile layout in a tall, elegant mobile viewport with minimal `↑ Portrait View` pill.
   - In **Horizontal Mode (→)**: Smoothly transforms and expands into wide landscape mode with minimal `→ Landscape View` pill (arrow pivots from `↑` to `→`).
   - Full-bleed responsive content with zero black bars and zero squishing.

3. **Cinematic, Buttery-Smooth Animations**:
   - **Immediate Entrance on Page Visit**: Smooth blur-to-focus typography reveal, ambient background lighting, and desktop website mockup gliding up with Apple-style levitation physics.
   - **Scroll Phase 1 (Reveal)**: Desktop mockup levels smoothly into center focus with an ambient halo.
   - **Scroll Phase 2 (True Fullscreen Zoom)**: Expands outward seamlessly to **100vw × 100vh** edge-to-edge full screen with zero margins, zero padding, and browser header rolling up.
   - **Scroll Phase 3 (Contract Back)**: Contracts smoothly back to centered `max-w-5xl` desktop card dimensions.
   - **Scroll Phase 4 (Mobile Transformation ↑ to →)**: Desktop morphs into the mobile viewport card, pivoting from vertical portrait to horizontal landscape.
   - **Scroll Phase 5 (Contact Us)**: Transitions seamlessly into the Contact Us section with staggered field reveal and live validation.

4. **Dark / Light Mode**:
   - Built-in theme switcher (`Sun`/`Moon` button in the navbar) with smooth color transitions and persistent state.
